# 0.1.3 — 2026-05-24

## Changed

- **`ref-element-search`** handler: category filter now prefers exact match before falling back to substring, so `"transition metal"` no longer inadvertently returns post-transition metals.
- **`ref-http-status`** service: numeric lookup rejects floats (e.g., `"404.5"`) — `parseInt` was silently truncating to a valid code. Only plain integer strings trigger numeric lookup now.
- **`ref-timezone-convert`** service: empty `from_tz` / `to_tz` strings now return an actionable error instead of matching everything (empty string matched via `startsWith('')`).
- **`ref-unit-convert`** service: absolute-zero guard uses a small epsilon (`-1e-9 K`) to absorb float imprecision, so `-459.67 °F` (exact absolute zero) is no longer rejected. Error message rewritten to show the computed K value clearly.
- **`ref-mime-type`** service: MIME parameters (e.g., `; charset=utf-8`) are stripped before lookup so agents passing raw `Content-Type` strings get a result instead of a miss.
- **`ref-element-lookup`** format: elements with `discovery_scientists === "Ancient"` render as `"Known since antiquity"` instead of the incorrect `"Ancient by Ancient"` string.
- **`ref-timezones`** resource: added `refTimezonesSlashCatchResource` (`ref://timezones/{region}/{city}`) to catch unencoded IANA IDs with a slash (e.g., `America/New_York`) and return an actionable error with the percent-encoded URI.

## Fixed

- **`ref-element-search`**, **`ref-geo-search`** handlers: replaced `Parameters<typeof service['method']>[0]` extraction with explicit inline object types, removing fragile dependency on internal service signatures.
- **`ref-unit-convert`** tool: removed stale `ConversionError` type import; handler now narrows the outcome inline.
- **`units-service`**, **`mime-service`**, **`constants-service`**, **`elements-service`**, **`http-status-service`**: replaced unsafe casts (`as (typeof arr)[number]`, repeated `as Record<string, ...>` casts) with `!` non-null assertions and a typed local alias (`const db = mimeDb as Record<string, MimeEntry>`), reducing cast noise without changing runtime behavior.
- **`elements-service`**: constructor now iterates `this.all` directly after assignment instead of the raw import; eliminates redundant re-cast per element.
- **`geo-service`**: language code lookup now uses the typed `TLanguageCode` import instead of an unsafe `as Record<string, { name: string }>` cast.
- **`units-service`**: removed `as never` casts on `convert().from().to()` calls; library types resolve correctly without them.
- **`ref-element-lookup`** tool: `DATASET_VERSION` constant exported from `elements-service` and referenced by name instead of repeated inline string literal.
- **`ref-countries`**, **`ref-elements`**, **`ref-timezones`** resource output schemas: description strings improved for nullable fields (capital, tld, atomic_mass, electronegativity_pauling, offset hours).
