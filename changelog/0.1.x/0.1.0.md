# 0.1.0 — 2026-05-24

## Added

- **10 tools:** `ref_geo_lookup`, `ref_geo_search`, `ref_timezone_lookup`, `ref_timezone_convert`, `ref_element_lookup`, `ref_element_search`, `ref_constant_lookup`, `ref_unit_convert`, `ref_http_status`, `ref_mime_type`
- **3 resources:** `ref://countries/{alpha2}`, `ref://elements/{number}`, `ref://timezones/{iana_id}`
- **geo-service** — country lookup and search from `countries-list` dataset (ISO 3166-1 α-2/3, languages, currencies, calling codes, timezones per country)
- **timezone-service** — IANA timezone lookups and conversions via Node.js `Intl` API + `@vvo/tzdb` metadata
- **elements-service** — periodic table with 118 elements sourced from PubChem/IUPAC 2024; full property set including atomic mass, electron configuration, electronegativity, density, phase, discovery data
- **constants-service** — CODATA 2022 physical constants (~360 entries) with fuzzy alias matching
- **units-service** — numeric unit conversion via `convert-units` covering length, mass, volume, temperature, speed, pressure, energy, power, frequency, digital storage, and angle
- **http-status-service** — IANA HTTP status code registry (~65 codes) with keyword search
- **mime-service** — MIME type lookups via `mime-db` (~1,000 types with extension mappings)
- No API keys, no runtime network calls — all datasets bundled at startup; works offline and in air-gapped environments
- HTTP and stdio transports; no auth required (read-only reference server)
