# 0.1.4 — 2026-05-24

## Changed

- **`package.json` scripts**: all `tsx scripts/<name>.ts` invocations replaced with `bun run scripts/<name>.ts`; `test` script changed from `vitest run` to `bunx vitest run`; `start:stdio` and `start:http` now invoke `bun ./dist/index.js` (replacing `node dist/index.js`); stale `start` alias removed.
- **`Dockerfile` build stage**: reverted from `node:24-slim` (with `npm install -g bun` workaround) back to `oven/bun:1.3`; build step now uses `bun run build` directly.
- **`package.json` `devDependencies`**: `tsx` removed.

## Added

- **`funding` block** added to `package.json` (GitHub Sponsors + Buy Me a Coffee).
