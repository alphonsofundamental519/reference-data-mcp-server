# 0.1.7 — 2026-05-30

## Changed

- **`ref_geo_search`** adopts enrichment: `totalMatches`, `truncated`, `appliedFilters`, and `notice` now surface in a typed `enrichment` block reaching both `structuredContent` JSON and `content[]` markdown trailer. Previously these were top-level `output` fields; they have been removed from `output` and moved into `enrichment`.
  - structuredContent: `total_matches` (output) → `totalMatches` (enrichment); `truncated` (output) → `truncated` (enrichment); `message` (output) → `notice` (enrichment). Values and semantics are preserved; key paths changed.
- **`ref_element_search`** adopts enrichment: `totalMatches`, `appliedFilters`, and `notice` now surface in a typed `enrichment` block reaching both channels. Previously these were top-level `output` fields.
  - structuredContent: `total_matches` (output) → `totalMatches` (enrichment); `message` (output) → `notice` (enrichment). Values and semantics are preserved; key paths changed.
- **`@cyanheads/mcp-ts-core` ^0.9.13 → ^0.9.16** — adopts three upstream releases including the `ctx.enrich()` API, `enrichment` / `enrichmentTrailer` builder fields, and `getEnrichment()` test helper.
